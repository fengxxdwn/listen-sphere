# 阶段 3：专业调音处理

## 完成状态

阶段 3 已完成。处理链适用于 Controller 接收的 Wi-Fi、蓝牙和 USB 远程声道；
本机 Windows 应用仍由系统 Audio Session 控制音量，不截获或修改单个应用 PCM。

## 实时处理链

1. 前级增益：-24 dB 至 +12 dB。
2. 噪声门：阈值 -80 dB 至 -10 dB，带平滑开启和释放。
3. 压缩器：阈值 -40 dB 至 0 dB，压缩比 1:1 至 20:1。
4. 十段图形均衡器：沿用 20 Hz 至 20 kHz、每段 ±20 dB。
5. 声道音量与分组总线：沿用声道静音、分组音量、分组 EQ。
6. 声道限幅器：天花板 -12 dB 至 -0.1 dB。
7. 远程声道混音与主软限幅器。

处理器按会话保存包络状态，不在实时路径分配集合或写日志；设备断连时会释放 EQ、
动态处理状态和混音缓冲。

## 语音闪避

- 任意声道可标记为“语音触发”。检测到高于约 -42 dBFS 的语音后保持 350 ms。
- 游戏、媒体或其他声道可标记为“被闪避”，衰减范围 0–30 dB。
- 默认建议：语音组作为触发源，游戏和媒体组作为目标。
- 采用约 60 ms 进入和 450 ms 恢复，避免音量突跳与频繁抽动。
- 声道调音面板显示门限、压缩增益衰减、闪避和限幅实时状态。

## 场景调音预设

场景保存全部声道的音量、静音、用途分组、十段 EQ、前级、噪声门、压缩器、限幅器、
语音闪避参数，以及分组总线、主音量和播放设备。支持：

- 新建或覆盖保存；
- 使用输入框重命名；
- 复制为新预设；
- JSON 导入和导出；
- 导入时重新分配 ID、处理重名并钳制所有数值范围。

## 自动验收

```powershell
dotnet build ListenSphere.sln -c Release --no-restore
dotnet test ListenSphere.sln -c Release --no-build
```

覆盖噪声门、压缩增益衰减、限幅天花板、语音闪避触发、版本 11 设置归一化，以及
既有协议、路由、传输、架构和 Windows 技术测试。

## 人工验收

1. 连接远程声道并打开其“原声/调音”按钮。
2. 提高前级，确认电平增加；触发声道限幅时状态显示“限幅保护”。
3. 开启噪声门并提高阈值，确认低电平底噪被压低，正常语音仍可打开门限。
4. 开启压缩器，将阈值设为 -18 dB、比例设为 4:1，确认响度峰值更稳定。
5. 将语音声道设为“语音触发”，游戏或媒体设为“被闪避”，确认说话时目标平滑降低、
   停止说话后平滑恢复。
6. 保存预设，依次验证重命名、复制、导出、删除和重新导入。
7. 重启 Controller，确认处理参数和场景预设均可恢复。
