# ListenSphere P1 实施状态

## 已实现

- 枚举活动 Windows Render Endpoint，使用稳定 MMDevice ID 并标记默认设备。
- 对指定端点启动 WASAPI Loopback Capture。
- 捕获回调只复制到池化缓冲并投递容量为 32 的 Drop-Oldest 队列。
- 后台使用 Media Foundation 转换到 48 kHz、Float32、双声道。
- 输出 10 ms / 480 sample frame 的 `AudioFrame`，维护单调采样时间戳。
- 计算 Peak、RMS 和削波状态，UI 更新频率不超过 20 Hz。
- 向指定设备播放低幅度 440 Hz 一秒测试音，不修改端点主音量。
- 用户明确选择保存路径后，录制 10 秒标准化 Float32 WAV。
- Sender 提供设备刷新、开始/停止捕获、测试音、调试 WAV、状态和队列统计。

## 自动验证

- Release 构建：0 警告、0 错误。
- Core：默认格式、帧时长、设置版本、电平计算和跨块 10 ms 切帧。
- Windows：NAudio WASAPI 类型、真实端点枚举、稳定 ID 和默认设备标识。
- 既有架构与协议测试保持通过。

## 待人工验收

P1 在以下项目完成前保持“实现完成、验收待确认”：

1. 在 Sender 选择实际耳机或音箱，测试音从正确设备播放。
2. 播放浏览器或音乐应用，Peak/RMS 随声音变化。
3. 录制 10 秒 WAV，文件可播放且内容正确。
4. 连续开始/停止捕获 20 次，无设备占用残留。
5. 捕获期间拔出设备，应用不崩溃并显示可恢复错误。
6. 连续运行 10 分钟，内存不持续增长，队列丢弃不持续增加。

完成以上确认后才可将 P1 标记为通过并进入 P2。
