# Android generated branding

The approved source master will generate:

- `icon-foreground.png` (transparent adaptive-icon foreground)
- `icon-background.png` or an approved solid background color
- legacy launcher PNGs for mdpi, hdpi, xhdpi, xxhdpi and xxxhdpi

Android Studio Image Asset is the preferred generator. Copy its output into the
app's `mipmap-*` directories. The current app resources remain an explicitly
temporary development icon until then.
